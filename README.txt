# E•RIDE TUNING – kostenlose Website

1. Öffne `index.html`, um die Website lokal im Browser zu testen.
2. In `index.html` die Adresse `DEINE-EMAIL@BEISPIEL.DE` durch deine eigene E-Mail-Adresse ersetzen.
3. Für die kostenlose Veröffentlichung kannst du z. B. GitHub Pages verwenden.
4. Vor dem Verkauf solltest du ein korrektes Impressum und – soweit erforderlich – eine Datenschutzerklärung ergänzen.
5. Die Seite ist bewusst so formuliert, dass sie die Nutzung auf Privatgelände hervorhebt und keine Anleitung zum Umgehen von Sicherheits- oder Hersteller-Schutzmechanismen enthält.
