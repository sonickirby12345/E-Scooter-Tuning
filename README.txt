E•RIDE TUNING – GitHub Pages Version

1. Entpacke die ZIP-Datei.
2. Lade index.html und style.css in dein GitHub-Repository hoch.
3. Aktiviere Settings > Pages > Deploy from a branch > main > /(root).
4. WICHTIG: Ersetze in index.html DEIN NAME / DEIN UNTERNEHMEN und DEINE-EMAIL@BEISPIEL.DE durch deine echten Angaben.
5. Passe die Beispielpreise an dein tatsächliches Angebot an.
6. Impressum und Datenschutzerklärung sind Vorlagen und sollten vor dem geschäftlichen Einsatz an deine konkrete Situation angepasst bzw. rechtlich geprüft werden.
7. Der Kaufen-Bereich löst absichtlich noch keine Zahlung aus; er erstellt eine E-Mail-Anfrage. Für echte Online-Zahlungen brauchst du einen passenden Zahlungs-/Shopanbieter und zusätzliche rechtliche Anforderungen.
